# AETIA — manuscript

Auditable multimodal pathogen selection from mNGS and clinical evidence in lower respiratory tract
infection (KMUH, TVGH, TSGH). Pipeline code lives in `../Multimodal-Diagnosis-Model`; this folder is
the paper only.

## Layout

```
main.tex                  skeleton, macros (\toolname, \todo, model names), title, authors, abstract, Figs. 1-3, Table 1
sections/introduction.tex results.tex  discussion.tex  methods.tex
Supplementary.tex         Supp. Fig. 1, Supp. Tables 1-5 (feature tiers, scorer tiers/levels, 33 guardrails,
                          module thresholds, model/prompt inventory with SHA-256), Supp. Notes 1-5
references.bib            GENERATED by notes/resolve_refs.py from Crossref (DOI list in that script); do not hand-edit
figures/                  fig1_overview, fig2_benchmark, fig3_llm_comparison (.svg generated, .pdf via rsvg-convert); supp/figS1_cohort_flow
figures-source/           make_fig1.py make_fig2.py make_fig3.py make_figS1.py; svgkit.py (SVG primitives), icons.py (flat vector
                          icon set: modalities, microbe glyphs, symbols; preview with _icon_sheet.py), charts.py (precision-recall
                          plane with iso-F1 curves, grouped/single bars); metrics.csv, burden.csv (every plotted number + provenance)
tables/                   make_table1.py -> table1_cohort.tex (generated from the cohort workbook, which stays OUTSIDE the repo)
notes/sources.md          ledger: each slide / workbook / code fact -> where it is used -> verification status
notes/resolve_refs.py     Crossref -> references.bib
Makefile                  `make` (both PDFs), `make figures`, `make wordcount` (also prints \todo counts), `make clean`
```

Build: `make` (TeX Live 2025: latexmk, `naturemag.bst`; `rsvg-convert` for figures; Python 3 with
`openpyxl` for Table 1). Table 1 needs `COHORT_XLSX` (default `../三院-final-mNGS merged file.xlsx`).
Figures are pure-SVG scripts with no matplotlib dependency; edit the script, not the SVG. Canvases are
1,000 units = 180 mm (Nature double column); body text 13 units ≈ 6.6 pt, minimum 9 units ≈ 4.6 pt.
Fig. 1 is pictorial (vector icons per modality, microbe glyphs, a sieve for the deterministic stage, an OR gate
for R5); Figs. 2a and 3a are precision–recall planes with iso-F1 curves so the recall gain of the pipeline is
read directly; identity in the crowded direct-prompting cluster is carried by marker shape plus an in-panel key.

## PHI policy

The cohort workbook and both decks stay in `../` and are not tracked here. `tables/make_table1.py`
reads the workbook by path and writes counts, percentages and medians only. Before any commit or
share, run `grep -rnE "Hospital_ID|19[0-9]{4}|[0-9]{6}_[0-9]{3}[A-Z]" --include=*.tex --include=*.csv --include=*.md --include=*.py .`
and `git status --ignored` and confirm nothing patient-level is present.
