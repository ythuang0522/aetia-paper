# AETIA — manuscript

Multimodal integration of metagenomic and clinical data for pathogen identification in lower respiratory tract infection
(KMUH, TVGH, TSGH; title settled 2026-09-21). Pipeline code lives in `../Multimodal-Diagnosis-Model`; this folder is
the paper only. Sources: https://github.com/ythuang0522/aetia-paper (private). Compiled PDF, supplementary
and figure previews: https://claude.ai/artifact/PB2BPxhvChugJsDavnGsKf (private artifact; re-upload the PDFs
there after each build that should be shared).

## Layout

```
main.tex                  skeleton, macros (\toolname, \todo, model names), title, authors, abstract, Figs. 1-3, Table 1
sections/introduction.tex results.tex  discussion.tex  methods.tex
Supplementary.tex         Supp. Tables 1-5, Supp. Notes 1-6 (feature tiers, scorer tiers/levels, 33 guardrails,
                          module thresholds, model/prompt inventory with SHA-256), Supp. Notes 1-6
references.bib            GENERATED by notes/resolve_refs.py from Crossref (DOI list in that script); do not hand-edit
figures/                  fig1_overview, fig2_benchmark, fig3_llm_comparison, fig4_explanation (.svg generated, .pdf via rsvg-convert); ed1_cohort_flow, ed2_registry, ed3_trajectory (Extended Data Figs. 1-3)
figures-source/           make_fig_overview.py make_fig_benchmark.py make_fig_llm.py make_fig_explain.py make_figED1.py make_figED2.py make_figED3.py; retired/make_fig_problem.py (not built)
                          (scripts are named by content; figure files carry the printed number); svgkit.py (SVG primitives), icons.py (flat vector
                          icon set: modalities, microbe glyphs, symbols; preview with _icon_sheet.py), charts.py (precision-recall
                          plane with iso-F1 curves, grouped/single bars); metrics.csv, burden.csv (every plotted number + provenance)
tables/                   make_table1.py -> table1_cohort.tex; make_discordance.py -> figures-source/discordance.csv +
                          discordance_summary.json (Supp. Note 6). Both read the cohort workbook, which stays OUTSIDE the repo;
                          only aggregates and de-identified per-detection rows are written out
notes/sources.md          ledger: each slide / workbook / code fact -> where it is used -> verification status
notes/resolve_refs.py     Crossref -> references.bib
Makefile                  `make` (both PDFs), `make figures`, `make wordcount` (also prints \todo counts), `make clean`
```

Build: `make` (TeX Live 2025: latexmk, `naturemag.bst`; `rsvg-convert` for figures; Python 3 with
`openpyxl` for Table 1). Table 1 needs `COHORT_XLSX` (default `../三院-final-mNGS merged file.xlsx`).
Figures are pure-SVG scripts with no matplotlib dependency; edit the script, not the SVG. Canvases are
1,000 units = 180 mm (Nature double column); body text 13 units ≈ 6.6 pt, minimum 9 units ≈ 4.6 pt.
Fig. 1 is pictorial (vector icons per modality, microbe glyphs, a funnel of four numbered filters for the deterministic
stage, an evidence matrix for the tracing stage — rows = carried candidates, columns = literature / sequencing / direct
tests / colonization with pictorial headers and glyph cells — and an OR gate for the final rule) and carries concept
labels only — no tier codes (V/O/R/D/M/C), no rule counts, no thresholds; a two-entry key (violet chip = language model,
cog = deterministic rule) marks the division of labour (PI's requests, 2026-09-21: readers should not have to remember
level classes; panels must be glyph-rich, not text-based). Figs. 2a and 3a are precision–recall planes with iso-F1 curves so the recall gain of the pipeline is
read directly; identity in the crowded direct-prompting cluster is carried by marker shape plus an in-panel key.
